Origin Server offers an Azure full-origin stack and a separate Amazon Web Services (AWS) Juice Shop deployment. Choose the workload your demonstration requires.

## Deployment choices

| Offering | Workload | Runtime |
| --- | --- | --- |
| Azure full-origin | Multiple vulnerable applications and mock APIs | Containers with nginx routing on an Ubuntu virtual machine |
| AWS Juice Shop | Juice Shop | Private Fargate tasks behind an Application Load Balancer |

The AWS offering does not reproduce the Azure application stack. Review ingress, access, and integration requirements in the [Origin Server deployment comparison](https://f5-sales-demo.github.io/origin-server/en/).

Use the selected application behind F5 Distributed Cloud to demonstrate web application firewall (WAF), API Protection, Bot Defense, or Client-Side Defense scenarios. The scenario and policy determine the evidence you need to verify protection.

[Origin Server guides](https://f5-sales-demo.github.io/origin-server/en/) provide architecture, application details, deployment inputs, verification, and cleanup.
