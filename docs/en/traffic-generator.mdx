Traffic Generator produces controlled security traffic and browser scenarios against an authorized F5 Distributed Cloud demonstration endpoint. Choose the Azure deployment or the independent Amazon Web Services (AWS) worker deployment.

## Deployment choices

The Azure offering installs its toolset on a virtual machine through cloud-init. The AWS offering uses a worker with explicit network access controls, pinned runtime inputs, and browser evidence capture. Their cloud configuration, runtime, and detection evidence differ.

Suites include web application firewall (WAF) payloads, bot simulation, API abuse, and Client-Side Defense browser scenarios. A completed scenario proves execution; verify the relevant F5 Distributed Cloud event before claiming detection or mitigation.

[Traffic Generator guides](https://f5-sales-demo.github.io/traffic-generator/en/) provide the deployment choices, tool catalog, suite instructions, verification, and cleanup.
