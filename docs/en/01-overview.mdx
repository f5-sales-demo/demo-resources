Choose an origin workload, then add a traffic generator or content delivery network (CDN) simulator when your demonstration needs it. Use each component's deployment guide for access requirements, tool versions, verification, and cleanup.

## Component selection

| Component | Purpose | Deployment choices |
| --- | --- | --- |
| [Origin server](../origin-server/) | Applications and APIs behind F5 Distributed Cloud protection | Azure full-origin stack or separate AWS Juice Shop deployment |
| [Traffic generator](../traffic-generator/) | Controlled security traffic and browser scenarios | Separate Azure and AWS offerings |
| [CDN simulator](../cdn-simulator/) | Proxy requests with vendor CDN headers | Azure virtual machine |

Azure and Amazon Web Services (AWS) offerings have different workloads and runtimes. Scenario execution does not by itself prove an F5 detection or mitigation. Follow the selected guide's verification steps and inspect the corresponding security evidence.

## Deployment requirements

Check the component guide for cloud access, Terraform and cloud CLI versions, network access, and required inputs. An Azure subscription does not satisfy AWS access requirements. Use only authorized demonstration environments.

- [Origin deployment comparison](https://f5-sales-demo.github.io/origin-server/en/)
- [Traffic generator deployment choices](https://f5-sales-demo.github.io/traffic-generator/en/)
- [CDN simulator deployment guide](https://f5-sales-demo.github.io/cdn-simulator/en/03-deploy/)

Review the Terraform plan and the cloud cost estimate before provisioning. Keep credentials and state out of source control.

## Integration order

1. Deploy the origin workload and verify its application health.
2. Configure the F5 Distributed Cloud origin pool and HTTP load balancer with the selected security policy.
3. Deploy the traffic generator or CDN simulator with the endpoint required by its integration guide.

## Verification and cleanup

Use the selected component's health checks and demonstration verification steps. Confirm both the workload response and the relevant F5 Distributed Cloud telemetry. Follow its cleanup guide when the environment is no longer needed to stop cloud charges.
